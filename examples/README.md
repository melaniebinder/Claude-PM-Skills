# Examples

All data is synthetic. The four worked examples follow one fictional company, *Helply* (a B2B helpdesk), from idea to launch decision:

1. [AI Feature Spec](../skills/ai-feature-spec/README.md#example-input): spec Suggested Replies, an LLM-drafted reply feature for support agents.
2. [PRD Stress Test](../skills/prd-stress-test/README.md#example-input): review a teammate's PRD that proposes taking the human out of the loop.
3. [Experiment Design](../skills/experiment-design/README.md#example-input): design the A/B test that decides whether Suggested Replies ships.
4. [Exec Narrative](../skills/exec-narrative/README.md#example-input): turn the test results into a launch and funding decision for leadership.
